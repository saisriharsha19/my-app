# Design research

Twelve personal and creative websites were reviewed for this redesign. Their content, project organization, and available visual references informed the following independent direction; no source code or branding was copied.

| Reference | Idea carried into this site |
| --- | --- |
| [Brittany Chiang](https://brittanychiang.com/) | Biography, experience, projects, and writing as one coherent professional story |
| [Rauno Freiberg](https://rauno.me/) | A recognizable identity and careful, restrained interaction details |
| [Paco Coursey](https://paco.me/) | Concrete projects paired with personal engineering perspective |
| [Emil Kowalski](https://emilkowal.ski/) | Concise project descriptions and a clear place for writing |
| [Lee Robinson](https://leerob.com/) | A direct biography and notes that reveal how the person thinks |
| [Josh W. Comeau](https://www.joshwcomeau.com/) | Helpful reading structure and human, approachable technical writing |
| [Bruno Simon](https://bruno-simon.com/) | Giving the portfolio its own visual world and moments of play |
| [Dan Mall](https://danmall.com/) | Clear positioning and a deliberate path to a conversation |
| [Adham Dannaway](https://www.adhamdannaway.com/) | Connecting engineering and the visitor experience |
| [Lynn Fisher](https://lynnandtonic.com/) | Expressive identity, unexpected details, and typography with personality |
| [Maggie Appleton](https://maggieappleton.com/) | Treating writing as an ongoing place for learning and thinking |
| [swyx](https://www.swyx.io/) | Linking public projects and writing into a discoverable profile |

The resulting identity uses a paper-and-teal editorial layout, an actual portrait, a geometric monogram, conceptual project illustrations, and concise personal context grounded in the existing website and GitHub profile.
